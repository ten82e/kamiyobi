見方のてびき（JST・AoE・「推定」の意味）
日時
日本時間（JST）と曜日を最初に表示する。2 行目は公式ページの表記で、表と詳細で同じ式を使う。
残り
「あと N 日」（14 日以内は強調）・「あと N 時間」（当日）・「まもなく」（1 時間未満）と出す。過ぎた締切は「本日終了」「N 日前に終了」で、**日数は JST の暦日**で数えます（JST で昨日終わった締切は「1 日前に終了」です。経過時間では数えない）。過去の行は既定では一覧に出さない（「過去の締切も表示」をオンにすると見える）。公式で時刻を確認できていない日付は「時刻未確認」とし、残り日数を計算していない。
AoE
Anywhere on Earth（UTC-12）の略。「世界のどこかでその日が終わるまで受け付ける」という国際会議の締め方。AoE 2026-02-06 23:59 は JST では 2026-02-07 20:59 で、日本では AoE の翌日まで提出できる。AoE を併記するのは公式が AoE 締切のものだけで、JST 宣言の国内会議には出さない。
時刻未確認
締切日だけを公式で確認し、時刻とタイムゾーンが未確認のもの。UTC+14 の始まりから UTC-12 の終わりまでを幅に持つため、表示した日より前に終わっている可能性がある。日付に添える曜日は暦日そのもの（閲覧者のタイムゾーンで前後しない）。
推定
前年までの実績から機械的に置いた未確認の値。公式サイトで裏が取れるまで確定扱いせず、既定では一覧に出さない（2026-09-23 時点の収録で 134 件。件数欄に「推定 N 件（『推定締切を含める』で出ます）」と出す）。推定 は検索の語としても引ける（「推定 機械学習」のように他の語と組み合わせられる）。「推定」で行が出るのは「推定締切を含める」をオンにしたときだけ。推定行は開催地がまだ空なので、開催地との組み合わせでは出ない。
再確認待ち・要確認
公式ページの見直しを予定している状態、または本文から締切を 1 つに確定できなかった状態。行を選ぶと確認元・確認範囲・次回確認予定が出る。
延長後
上流の締切名に Extended（延長）と付いていた行です。もともとの締切が延びて、一覧に出している日付が延長後の締切です（元の日付は上流も保持していません）。2026-09-23 時点の収録では、既定の一覧（478 行）に出る延長の目印は 9 行、収録全体では 33 件（採否通知など表に出さない種別も含む）。延長 は検索の語としても引けます（「延長 機械学習」のように他の語と組み合わせられる）。
締切まで
締切日からの日数で絞ります（開催日ではありません）。「過去の締切も表示」と一緒にすると、同じ日数の前後の窓になります（「先週出た締切と今週の締切」を見るためで、過ぎた締切が片端から残るのではありません）。既定は「かまわない」で、期限なく先の締切も出します。窓で外れた件数は件数欄に「「締切まで 7 日以内」を超える N 件」として出ます（実測で「7 日以内」は 478 行中 39 行だけが出るところで、のこり 439 行はこの窓の話です。収録が薄いわけではありません）。戻すときは選択欄を「かまわない」にしてください。
画面上部の四つの数
いずれも絞り込み前の収録全体の数字です（検索や絞り込みで動きません）。単位をラベルに書いています: 「収録している会議」と「穴場として収録した会議」「国内研究会・国内シンポジウム」は会議の数、「これからの30日間の締切」だけ締切の件数（概要締切と論文締切を、推定を除いて数えます）。「穴場として収録した会議」は収録側が niche とタグ付けた会議、「国内研究会・国内シンポジウム」は同じく domestic-jp とタグ付けた会議で、チェックボックスの絞り込みと同じ集まりです。一覧に出る行数は件の欄（例: 「478 件 / 全 3,235 件」）を見てください。
過去の締切も表示
締切を過ぎた行も出します。収録している投稿締切は 2019 年ごろまで遡れ、過去分も種別・ランク・検索語で絞れます。チェックだけでは期間の限定がないので全履歴が出ます。過ぎた行は一覧の下にまとめて出し、「過ぎた締切（N 件）」の見出しを置きます（まとめないと 2019 年の行が画面の先頭を埋め尽くし、これからの締切がすべてその下に沈むためです）。塊の中は選んだ列の向きそのままに並ぶので、直近に締切ったものから見たいときは「残り」を押して降順にしてください。「締切まで」と一緒に選ぶと、同じ日数の前後の窓になります。去年この会議の締切はいつだったかを確かめるときに使ってください。
CSV
「表示中の N 件を CSV でダウンロード」は、いまの絞り込みで残った行だけを書き出します（ページ送りで画面に出ている分ではなく、絞り込み後の全行です）。条件を一切外さない一覧が欲しいときは「条件クリア」を押してから書き出してください。日時は JST、日付だけが分かっている行は「時刻未確認」と書きます。「残り」列は日数の数値（過ぎた分は負の数）なので、表計算での並べ替えや絞り込みに使えます。分野列も入っています（画面の分野チップと同じ日本語の語。hpc のような内部のキーは書きません）。一覧は分野列を持たないので、分野ごとに並べたり分野で絞ったりしたいときは CSV のほうを使ってください。Excel で開いても文字化けしないよう BOM を付けます。投稿先を探す画面では CSV は出しません（絞り込みの結果ではないため）。
並び順
列の見出し（残り・日時・会議・ランク）を押すと並び替わります。押している列だけが ↑ / ↓（他は ↕）なので、今の画面が何の順で並んでいるかを見出しだけで確かめられます。支援技術には、件数といっしょに「並び順: 残り 昇順」のように読まれます（見出しの矢印は読んでも変わらないので）。残りの昇順（既定）と日時の昇順では同じ月の締切をまとめて区切るため、降順にすると月でくくれた行になります。同じ締切日・同じランクの行が並んだときは、表に出る会議名（日本語は読み基準の五十音順）→ 種別（概要・論文）の順でぞろえます。狭い画面（スマートフォンの幅）では列の見出しを消して行をカードにするため、代わりに表の上に 並べ替え の列を出します（押している列だけ ↑ / ↓）。ランク は評価の体系名ではなく等級で並びます（降順がいちばん評価の高い行から。変更前は体系名が先に効いて、降順でも評価の付いていない行が先頭に来ていた）。複数の評価を持つ会議は最良の等級で入り、評価の無い行は降順では末尾に回ります。並び順も URL に残るので、そのまま共有可能です。
キーボードで一覧を動かす
j / k（または ↓ / ↑）で選択行を動かし、Enter で公式ページを開き、d で行の詳細を出します。選んだ行にはフォーカスも一緒に動くので、支援技術では行の内容が読まれます。/ を押すと検索欄に飛び、Esc で詳細を閉じます。入力欄の中ではこれらのキーはただの文字として扱われるので、検索語に j や k を含んでも行は動きません。投稿先を探すモードでは表用の操作は使いません。

分野の言い方
「スパコン」「可視化」「ヒューマンインタフェース」のように口にする語で打つと、表に出している分野名に寄せて探します。締切種別も同じで、「抄録」「要旨」は「概要締切」、「全文」「本論文」は「論文締切」に寄せます（学会の募集文は「抄録締切」と書くことが多いので）。寄せたときは件数欄に「「スパコン」は分野「高性能計算」で探しています」と出すので、なぜその行が出たか分からないまま行数の壁になることがありません。もともと精密に引ける語（「機械学習」など）は寄せません。分野でしぼりたいときは分野チップを押してください。 チップで絞ったときは件数欄に「分野「人工知能」を持たない行 N 件」も出ます（2026-09-23 実測: 既定画面 478 行のうち「人工知能」は 182 行で、のこり 296 行はこの話でした。2 つ以上のチップは OR なので、押すほど増えます）。チップに書かれる件数はその分野の行の数、件数欄の件数は「他の条件を通った行のうち分野で落ちた数」なので、足しても全件にはなりません。 チップは Tab で届き、Space で入り・出ます（押しているチップには枠が出ます）。
国内
情報処理学会・電子情報通信学会などの国内研究会と国内シンポジウムに絞ります。「国内研究会」のボタンでも同じ絞り込みができて、件数欄にはのぞいた件数も出ます。日本の開催かどうかとは別物で、日本で開催される国際会議（開催地が `Tokyo, 日本` のように書かれる行）はここを付けると消えます。日本開催の会議を見たいときはチェックを外し、検索に「東京」「日本」などと打ってください。日本の行の開催地はローマ字で書かれていますが、漢字で打てます（東京 京都 名古屋 会津若松 など。会場名で行を書いている回は 一橋講堂 日本科学未来館 でも引けます。行には Aizuwakamatsu, 日本 のまま出ます）。宮古島 のように、寄せてあるものは公式の表記（Miyakojima, Japan）に対応しています。逆に、行の無い地名（宮島 など）は置いていません。
種別
表は投稿締切（概要・論文）だけを出します。採否通知・カメラレディ・登録締切・開催案内などは表に混ぜず、upcoming.md に載せます。種別の選択欄に並ぶのは、選べば結果が返る種別（概要・論文・常時受付）だけです。
行の詳細
行を押す（タップする）と、右から詳細の出る欄が開きます。閉じるときは、開いた欄の右上にある ✕（閉じる）を押します。キーボードなら j / k で選択行を動かしてから d で開け、Esc で閉じられます。中身は、公式ページへのリンク、開催地と会期（JST と曜日）、分野、評価、締切の確認状況（いつ・何を公式で確認したかと、次回確認の予定）、日付だけが分かっている締切のただし書き、同じ研究会のこれからの回（研究会は毎月開くので、行をめくらなくても次の回が分かります）。一覧に出ない情報はこの欄に有りますが、投稿前に公式サイトで最新の募集要項を確認してください。
一致評価の出し方（投稿先を探す）
2つの検索の順位を合わせて決めます。言葉の一致（論文の単語が会議の情報に含まれるか）と、意味検索（文の意味の近さで探す検索）です。「一致評価 … ▾」のチップを押すと、その行の下に内訳（どの要素でどれだけ合ったか）が出ます。マウスはもちろん、Tab でチップに移動して Enter または Space でも開けます（もう一度押すと閉じます）。数値は並べ替えるための目安であり、採択される可能性の予測ではありません。
この論文との合い方（順位の形にして示すもの）は、カードの頭にある一致評価のチップに一度だけ出します（日時は表と同じ向きで、JST と曜日を主に、公式ページの表記を添えます）。その下に、並びとは別の判断材料を4行並べます。会議の続いている年数（何年分の会期を確認し、その会議の論文を何件収録しているか）、種別（論文募集なのか採択通知かなど）、締切の確認状況（日付・時刻・タイムゾーン・種別をそれぞれ公式で確認できたか）、取得状態（その締切を今回上流にあたって確認したのか、前回の取得データや収録データで出しているのか）です。取得状態が「今回は上流にあたらず」を出している行は、上流の日付が変わった可能性があるので、投稿先を決める前に公式サイトの締切を確認してください。
未確認
会期・開催地・ランクの値が空のセルは「未確認」と出します（「-」などの記号ではありません）。会議側が未定にしていることとは別で、kamiyobi が公式で裏を取れていないという意味です。空のまま置きたくない情報は公式の発表を待つしかありません。
早め絞り込みのボタン
画面上部のボタン（「締切まで 7 日以内」「A*ランク」「高性能計算・システム」「国内研究会・国内シンポジウム」「オンライン参加可」）は、その条件だけを出し入れします。押すと入ってもう一度押すと外れ、押している間は点いたままです。入力済みの検索語や他の条件は消えません（変更前は押すたびに初期値へ戻っていました）。条件を一度に外したいときは、0 件案内の「条件をまとめて外す」を使ってください。

海外の開催都市
カタカナで引けます（リール ストラスブール チェジュ バンガロール など）。行には公式の英文字表記が残りますが、日本語の表記表が同じ都市のつづりに寄せます。収録カタログに 5 行以上現れる都市は検査で見ているので、会議が増えて表記表が追いついていない日に検査が落ちます（この検査は 2026-09-23 までアクセント記号付きの都市名を拾えていませんでした。検索がアクセントを捨てるので、数え上げも同じくアクセント記号を除いて行うように直しています）。カンクン・マルメ・テュービンゲン・マラガ・クラクフ・ロングビーチ・ヴェローナ・サクラメントなど、アクセント記号付きで収録されている都市もカタカナで引けるようになりました（Cancún は収録 23 行ありながら、変更前は カンクン で 0 件でした。行には Cancún のまま出ます）。ワシントン はワシントン州の行にも当たり、バリ はインドネシアの島とイタリアのバーリの両方に当たります（行の開催地に国・州が併記されるので、そこで判別してください）。
国内研究会・国内シンポジウム
「国内研究会」は検索の語としても引けます（変更前はチェックボックスの語なのに検索では 0 件でした）。行の名前に「研究会」と書かれた国内の行だけを指すので、チェックボックス（国内の行すべて）より狭くなります。
オンライン参加可
会場表記に「オンライン」「ハイブリッド」「Online」「Virtual」などの記述がある行だけを出します。記述が無い行を対面とは判定しません（公式サイトで確認してください）。会場名の一部として語が含まれる例（KSIR Virtual Conference Center）は除外しています。実測で既定画面 478 行のうちこの条件に書くのは 15 行だけで、のぞく 463 件のうち 110 件は開催地自体が未確認です。（この頁に書いた実測値は、収録データを固定時刻で組み直した成果物に対して毎回検査しています。ズレたら検査が落とします）件数欄は「オンライン参加の記載がない N 件（うち開催地が未確認 M 件）」と分けて出すので、オンライン参加が無いのだと誤解しないでください。行の詳細には開催地の公式表記をそのまま載せています。（hybrid） のような対面併用の表記もオンライン参加可として数えます（英語表記だけを理由に落ちる不整合を 2026-09-23 に修正。収録 97 件 → 117 件）。このチェックボックスの語はそのまま検索の語にもなっていて、「オンライン参加可」「オンライン参加」「ハイブリッド」と打っても同じ行が引けます（広げた先は件数欄におしらせを出す）。
会期のみ・締切未定
研究会は会期だけ先に決まり、締切が後から出るのが普通です。締切の無い回は表に載せず、upcoming.md に会期を載せます。表が 0 件でも、検索語に合う次回会期があればその場に出します。 表に行が出ているときも、件数欄に「同じ条件で会期だけが確定している会 N 件（締切は未定）」を出すので、一覧だけが全部だと受け取らないでください（変更前は 0 件のときの案内にしか無く、例えば「研究会」は表 16 件に対して会期だけの該当 28 件が画面に出ていませんでした）。行の詳細（ドロワー）には「今後の会期」として同じ研究会のこれからの回を併記します。これらの開催地の書き方は表と同じです（国は日本語、開催市は公式表記のまま。マウスを載せると原表記が出ます。変更前は「開催地: Kyoto, 日本」と並びに「＠Kyoto, Japan」が同時に出て、別の場所のように読めました）。
ランク
CCF・CORE・THCPL の評価一覧に基づきます。同じ会議でも一覧によって評価が違うので、絞り込みはいずれかの一覧その評価なら出します。評価一覧に載っているが評価が付いていないものは「CCF 評価なし」のように出します（データ内部の表記は N）。評価一覧そのものに載らない会議は「未確認」です。収録している穴場会議・ワークショップは基本的に載りません。 評価でしぼったときは件数欄に「評価「A*」を持たない行 N 件」も出します。選択欄には評価の収録数が写らないので、この数がないと「収録に A* が少ない」と誤解して絞り込みを外してしまうためです（2026-09-23 実測: 既定画面 478 行のうち「A*」は 61 行で、のこり 417 行がこの話でした）。
データ源
画面下の「データ源」は、収録データがどの配布物に基づいているかの表示です。名前はリンクで、クリックするとその配布物のページ（一次資料）に飛べます。「このサイトで収録した分（上流に無いもの）」は、上流の配布物に載っていない会議・締切をこちらで入力し、公式ページを確認して加えた分です（上流配布物のライセンスとは別の話なので、この項目にはライセンスを書きません）。評価（CCF・CORE・THCPL）の出典でもあることは「ランク」の項に書いています。どこまでが公開済みかは「データ更新」を見てください。
