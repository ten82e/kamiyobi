日時・残り・AoE・時刻

日時
日本時間（JST）と曜日を最初に表示する。2 行目は公式ページの表記で、表と詳細で同じ式を使う。行の詳細の中にある公式確認の日時（公式ページを見直した時刻と次回確認の予定）も同じ JST で出す。
残り
「あと N 日」（14 日以内は強調）・「あと N 時間」（当日）・「まもなく」（1 時間未満）と出す。過ぎた締切は「本日終了」「N 日前に終了」で、日数は JST の暦日で数えます（JST で昨日終わった締切は「1 日前に終了」です。経過時間では数えない）。過去の行は既定では一覧に出さない（「過去の締切も表示」をオンにすると見える）。公式で時刻を確認できていない日付は「時刻未確認」とし、残り日数を計算していない。日付だけの締切は、その日に入ると「締切日（過ぎた可能性）」、時刻の幅を過ぎると「締切日経過」と出します（幅のどこかで終わっているため、残り日数は数えません。時刻とタイムゾーンは「日時（JST）」の欄と行の詳細で確かめてください）。
AoE
Anywhere on Earth（UTC-12）の略。「世界のどこかでその日が終わるまで受け付ける」という国際会議の締め方。AoE 2026-02-06 23:59 は JST では 2026-02-07 20:59 で、日本では AoE の翌日まで提出できる。「元の日時」は収録データの表記で、公式サイトでの再確認状態とは別です。AoE を併記するのは収録元が AoE を指定しているものだけで、JST 宣言の国内会議には出さない。その場合、二つの欄で違う日付を書く行があります。元の日時に書く AoE の日付もそのまま検索の語になります（一覧の月のまとめ・並び順・残りの日数は JST の暦日で決まります）。
時刻未確認
締切日だけを公式で確認し、時刻とタイムゾーンが未確認のもの。UTC+14 の始まりから UTC-12 の終わりまでを幅に持つため、表示した日より前に終わっている可能性がある。日付に添える曜日は暦日そのもの（閲覧者のタイムゾーンで前後しない）。並び順・「残り」の日数・月のまとめ・CSV の残り日数は、表示している暦日で決まります。すでに終わったかどうかの判定だけは幅のままです。

推定・未確認・延長

推定
前年までの実績から機械的に置いた未確認の値。公式サイトで裏が取れるまで確定扱いせず、既定では一覧に出さない（件数欄に「推定 N 件（『推定締切を含める』で出ます）」と出す）。推定 は検索の語としても引ける（「推定 機械学習」のように他の語と組み合わせられる）。「推定」で行が出るのは「推定締切を含める」をオンにしたときだけ。
要確認・読み取り失敗・再確認待ち
行に出す印の語で、一覧に並ぶこの語はそのまま検索の語にもなります（要確認 は公式ページから締切を 1 つに確定できなかった行、読み取り失敗 は公式ページは取れたのに締切を読み取れなかった行、再確認待ち は公式ページの見直しを予定している行です。行の詳細には 確認済み も表示します）。確定できなかった理由は一つではありません – 公式ページを自動で見に行けない・候補が複数で一意に決まらない・本文が取れなかった、のいずれかです。理由を一つに決め打つ語は出しません。行を選ぶと公式確認（最後に確かめた日時。確かめていなければ「未確認」）・確認元（どこで確かめたか）・確認範囲（その記録が扱う欄。まだ確かめていない行は「まだ確かめていません」）・次回確認予定（次に見直す日）が出ます。確認元・確認範囲は日本語で出します。
過ぎた締切の印
「過去の締切も表示」で並ぶ行には、根拠の分かる範囲で三つの印を付けます。「締切済み（会期がこれから）」は投稿の締切を逃したけれど、その会議の会期はまだ先だという意味です。「締切済み（次回予定）」は同じ会議の次の回が収録で確認できている行だけに出します。「締切済み」は会期も過ぎて次の回が確認できていない行です。印は行の詳細の「今後の会期」と同じ判断を見るので、印と中身が食い違いません。
延長後
締切が後ろへ延びていた行に出す印です。もともとの締切が延びて、一覧に出している日付が延長後の締切です。情報源は二つあります。上流の締切名に Extended（延長）と付いていた行（元の日付は上流が保持していません）と、公式ページの差し替えを検知して前に出していた日付を持っている行です。以前の締切が記録されているときは、行を開くと「前に出ていた締切: 2026-09-27(日) → 2027-01-08(金)（延長）」の形で前に出ていた日付が出ます（その日付をそのまま検索欄に貼るとその行に出会えます）。日付が前へ動いた行には印を付けず、行の詳細に「（前倒し）」だけを出します – 会議が動かしたのかこちらの以前の記録が弱かったのかは分からないので、動作を推測した語は書きません。延長 は検索の語としても引けます（「延長 機械学習」のように他の語と組み合わせられる）。

締切まで・件数・過去

締切まで
締切日からの日数で絞ります（開催日ではありません）。「過去の締切も表示」と一緒にすると、同じ日数の前後の窓になります（「先週出た締切と今週の締切」を見るためで、過ぎた締切が片端から残るのではありません）。既定は「かまわない」（期間の限定を付けない）です。ただしこの一覧に差し込むデータは生成から 180 日先で切れています – それより先の締切は、件数欄の下に出る「収録の全体を読み込む」を押すと出てきます（押さない限りは読みに行きません）。カレンダー（deadlines.ics）にはこの一覧より先の締切も入っているので、画面で見えない先もカレンダーには載っています。窓で外れた件数は件数欄に「「締切まで 7 日以内」の対象外 N 件」として出ます。戻すときは選択欄を「かまわない」にしてください。選択肢は かまわない・7 日以内・30 日以内・90 日以内・180 日以内です。（画面上部の同じ窓のボタンについては「早め絞り込みのボタン」の項）
画面上部の四つの数
いずれも絞り込み前の収録全体の数字です（検索や絞り込みで動きません）。単位をラベルに書いています: 「収録している会議」と「穴場として収録した会議」「国内研究会・国内シンポジウム」は会議の数、「これからの30日間の締切」だけ締切の件数（概要締切と論文締切を、推定を除いて数えます）。「穴場として収録した会議」は収録側が niche とタグ付けた会議、「国内研究会・国内シンポジウム」は同じく domestic-jp とタグ付けた会議で、チェックボックスの絞り込みと同じ集まりです。一覧に出る行数は件の欄（例: 「478 件 / 全 3,235 件」）を見てください。「これからの30日間の締切」は、期間の選択で「30 日以内」を選んだときの一覧と同じ行を数えます。
過去の締切も表示
締切を過ぎた行も出します。収録している投稿締切は 2019 年ごろまで遡れ、過去分も種別・ランク・検索語で絞れます。期間の限定を外したので、過去の締切がすべて出ています。過ぎた行は一覧の下にまとめて出し、「過ぎた締切（N 件）」の見出しを置きます（まとめないと 2019 年の行が画面の先頭を埋め尽くし、これからの締切がすべてその下に沈むためです）。塊の中は選んだ列の向きそのままに並ぶので、直近に締切ったものから見たいときは「残り」を押して降順にしてください。「締切まで」と一緒に選ぶと、同じ日数の前後の窓になります。去年この会議の締切はいつだったかを確かめるときに使ってください。収録の全体の読み込みは表本体とは別に行うので、始まっている間は「収録の全体の締切を読み込み中…」、失敗したときは「収録の全体の締切の読み込みに失敗しました。いま表示している一覧は使えます」を出します。読み込みに失敗してもいま見ている一覧はそのまま使え、隣の「収録の全体の締切を再試行」でもう一度読めます。件数欄にも同じ名前で短く出るため、2 つの読み込みが始まったようには読めません。

CSV・並び順・共有・印刷・キーボード

CSV

「この一覧の N 件を CSV でダウンロード」は、絞り込み後の全行を書き出します。先頭40件だけの表示でも、件数欄に出る N 件ぶんが対象です。画面で続きを見るには「さらに表示」または「すべて表示」を押します。入力した検索条件を外して書き出すには、先に「条件クリア」を押してください。

日時は JST、日付のみの締切は「時刻未確認」と表示します。「残り」列は画面と同じ日数で、過去の締切は負の数です。分野列は画面の分野チップと同じ日本語です。会議列には開催年を添えた名前（例: 3DV 2024）が入ります。状態列には「会期未確認・開催地未確認」や、常時受付の「会期該当なし」も記録し、値が空の場合の理由を区別できます。

Excelで開けるようBOMを付け、ファイル名の YYYYMMDD は JST の日付に揃えます。「投稿先を探す」では「この候補 N 件を CSV でダウンロード」となり、カードと同じ候補・順位を書き出し、ファイル名は kamiyobi-candidates-YYYYMMDD.csv です。最初の4列は一致評価・一致の点・言葉の一致・意味の近さです。「一致の点」は順位を決める値で、「一致評価」の区分とは別の計算です。順位表に入るのは、会議名・主題などに実質的な一致がある投稿先です。意味検索を使っていない場合、「意味の近さ」は空欄です。

公開ファイル data.csv の列名は英語です。種別には日本語の列 kind_ja もあります。label は上流の自由記述なので、種別で並べ替える場合は kind_ja を使ってください。

JSON

「全データ（JSON）」は data.json を開きます。収録している全ての会議を 1 会議 1 件として、開催回ごとの会期・締切・出典をまとめています。過去の締切や、画面の表示期間より先の締切も含みます。収録件数は画面の件数欄または health.md で確認できます。

項目名は英語のキーです。分野は各会議の categories にキー（例: ai）で入り、正式名はファイル先頭の categories 対応表にあります。表計算で現在の絞り込み結果を使う場合はCSV、自分のプログラムで収録全体を読む場合はJSONを選んでください。

ファイルは一覧より大きく、取得に時間がかかることがあります。プログラムから …/data.json のURLを直接指定できます。読み方と関連ファイルの索引は、同じ場所の llms.txt にあります。

並び順

列の見出し（残り・日時・会期・会議・ランク）を押すと並べ替わります。選択中の列は ↑ または ↓、他の列は ↕ で表示します。狭い画面では表の上の「並べ替え」を使います。並び順はURLにも保存されます。読み上げでは「並び順: 残り 昇順」のように、選択中の列と向きを伝えます。会期の順は出張の計画に向きます。

会期が未確認の行は、昇順・降順のどちらでも末尾です。「残り」や「日時」の昇順では、締切の月ごとに 「締切 YYYY年M月（N 件）」の見出しで区切ります。会期順では月見出しを出しません。同じ締切日・ランクでは、会議名（日本語は読みを基準に五十音順）、種別の順に並べます。ランクは、複数の評価がある場合の最高評価で比較し、評価のない行は末尾に置きます。

画面を共有する

ブラウザーのアドレスをコピーすると、絞り込みと並び順を共有できます。未対応の値を含むURLでは、選択肢にある値へ戻し、変更した内容を画面に表示します。分野だけを変えたい場合は分野チップを切り替えてください。見方のてびきを開いた状態も ?help=1 で引き継ぎます。

行の詳細を開いたURLには ?row=… が入り、その行を指定します。必要な条件を外して行を開き、何を外したかを件数欄に表示します。通常の一覧に出さない種別や、会期のみの行も詳細を確認できます。旧リンクが複数の行に当たる場合は候補を選びます。収録に見当たらない場合はその旨を表示します。

「投稿先を探す」では行の詳細を閉じます。mode=recommend と行の指定を組み合わせたURLでは、開かない理由を表示します。共有URLに論文のタイトル・概要・キーワード・参考論文は含まれません。入力は同じタブの下書きとして保存され、ページの再読み込みで復元します。

印刷
ブラウザの印刷（Ctrl + P など）では、いま絞り込まれた 一覧の全行が出ます（画面では 40 行ずつしか描かないので、そのままだと 印刷物だけ途中までになってしまうためです）。表の上には、条件の書き下ろし・表示件数・ 印刷した日時（JST）・データ生成日時（JST）・並び順が紙に残ります。研究室に貼る・会議で回覧する ときに、条件の分からない一覧にならないためです。並び順は絞り込みではありませんが、同じ一覧を 会期順やランク順に並べ替えて配ることがあるので、紙のうえで何の順か分かります。ヘッダーの「データ生成」も印刷に残ります（生成から時間が経っているときの注意書きも一緒に残ります）。「投稿先を探す」画面で印刷したときは、紙に残るのは候補のカードと各候補の公式ページのアドレスです。カードは画面では上位 20 件ずつ出ていますが、紙には候補をぜんぶ載せます。このときの但し書きは「投稿先を探す画面 ／ 候補 N 件」となり、締切一覧の絞り込み条件は書きません（並んでいる物が別物なので、条件を書くと紙のうえで噓になるためです）。紙のうえには語の但し書きも一緒に刷ります（画面のてびきは印刷で隠れるので、受け取った人が紙だけで読めるようにするためです）。用紙には「この用紙の表記: …」の形で、「未確認」の付く語・「評価なし」・「ランク未確認」・「延長後」・「該当なし」・「公式表記」と「種別」の違い・CCF・CORE・THCPL の三列が空欄の意味・「状態」が空欄のときに何が言えるか・「AoE」が何を指すかが書かれます。紙に刷られない語（行の詳細にしか出ない語など）は書きません。
キーボードで一覧を動かす
j / k（または ↓ / ↑）で選択行を動かし、Enter で公式ページを開き、d で行の詳細を出します。/ で検索欄に飛び、その欄にいるときにEsc を押すと検索語を消さずに欄を出て、選んでいた行にフォーカスが戻ります（Esc は行の詳細を閉じるのにも使います）。選んだ行にはフォーカスも一緒に動くので、支援技術では行の内容が読まれます。入力欄の中ではこれらのキーはただの文字として扱われるので、検索語に j や k を含んでも行は動きません。列の見出しもキーボードで押せます（Tab で 残り ・日時（JST）・会期・会議・ランク の見出しから、狭い画面に出す並べ替えのボタンまで移動し、Enter（または スペース）を押すと並び替わります）。押している列は ↑ / ↓、他は ↕ になるので、どれが効いているかが見出しだけで分かります。条件のチェックや並び替えのボタンを押した直後も、そのまま打てます（ボタン自身の操作である Enter と Space だけがボタンに渡ります）。投稿先を探すモードでは表用の操作は使いません。

検索・日付・分野

検索

会議名・分野・主題・開催地・公式ページのURLで検索できます。公式ページのURLをそのまま貼り付けても検索できます。日本語の主題も英語の表記に対応します（例:「暗号」は cryptography）。略字の 〆 は 締 と同じ扱いです。欄の名前（「分野」など）より、値（例: オンライン参加可）で検索してください。

複数の語をスペースや ・ ， 、 / で区切ると、全ての語に当たる行を探します。全角文字や、語の前後の疑問符・括弧・句読点も扱えます。記号だけの入力は絞り込みません。助詞を含む文や「海外で開催される会議」のような表現も使え、件数欄に解釈を表示します。会議・大会、開催・実施など一覧全体に当たる語は、他の語と一緒に入力した場合は絞り込みに使いません。

日付の検索は締切の日付と会期の日付の両方を見ます。8月21日 2027年8月21日 2027-08-21、月なら 12月 2027年12月 のように入力します。年を付けるとその年に限定します。1月 で 11月、1日 で 11日・21日・31日 は探しません。締切欄・会期欄の表示をそのまま貼り付けても検索できます。「締切まで」の選択欄は締切からの日数で絞るので、日付の検索とは対象が異なります。

「今月」「来月」「再来月」「先月」「今年」「来年」「去年」「再来年」「明日」「今週」「来週」も使えます。日本時間の暦として解釈し、週は月曜始まりです。件数欄で解決した年・月・日を確認できます。曜日は締切の日を対象に「金曜日」「水曜」「週末」（土曜日・日曜日）「平日」（月曜日〜金曜日）の形で検索します。

会議名に年を付けた ACISP 2027 nsdi27 ICDE2027 や、略称と2桁の年を離した入力も使えます。会議名のない 27 は年とは決めません。数字だけでは広く当たるため、25日・8月・2027年 のように単位を付けてください。ラウンドは 第 2 ラウンド 第2ラウンド R2 で検索でき、1 ラウンド目は表に番号を添えませんが、第 1 ラウンド や R1 でも検索できます。時刻やランク、分野名も画面の表記で検索できます。

開催地は「おきなわ」「しこく」「首都圏」「東海地方」「シアトル」「米国」「上海」などの日本語でも探せます。海外の地域名（「ヨーロッパ」「北米」「南米」「中米」「中東」など）も使えます。「中国」は国と地方の両方を探すので、地方だけなら「中国地方」と入力してください。「バリ」のように複数の地名に対応する語は、その対応を件数欄に表示します。アクセント付きの Montréal と montreal も同じ扱いです。

主題の例は「リアルタイム」「プログラミング言語」「仮想現実」「データ分析」「脆弱性」「マルウェア」などです。表記によって見つからない場合は、「画像認識」を「画像」「パターン認識」に変えるなど、別の語でも試してください。公式URLで見つからない場合も、会議名で探せます。常時受付のジャーナルを表示するには「種別」で「常時受付」を選びます。

0件になったら件数欄の案内を確認してください。収録の範囲、足りない語、適用中の条件による除外を区別して表示します。「締切」「提出期限」のように一覧全体を指す語や、短い入力で絞れない場合も打ち直し方を案内します。日本語入力は変換が確定してから絞り込みます。

日付の言い方
今日 明日 明後日 今週 来週 今年 来年 はその暦日・暦月語に解決して引きます。中 を付けた言い方も同じ解決をします（今日中 本日中 明日中 今週中 来週中 今月中 来月中）。『今日中』は今日の話、『今週中』はその週の話で、別の日数を足す意味にはしていません。「残り」欄に並ぶ語もそのまま貼れます（あと 51 日 → 51 日先の暦日。51日後・3 日前 の言い方でも同じ）。数え方は一覧と同じ JST の暦日です。黙って条件を変えたように見せないため、解決した日付は件数欄に出します（51日後 = 2026年9月29日(火)）。5日 のように数値だけの日は「今月の 5 日」と読んで、日数の言い方には寄せません。
分野の言い方
「スパコン」「可視化」「ヒューマンインタフェース」のように口にする語で打つと、表に出している分野名に寄せて探します。締切種別も同じで、「抄録」「要旨」は「概要締切」、「全文」「本論文」は「論文締切」に寄せます（学会の募集文は「抄録締切」と書くことが多いので）。寄せたときは件数欄に「「スパコン」は分野「高性能計算」で探しています」と出すので、なぜその行が出たか分からないまま行数の壁になることがありません。もともと精密に引ける語（「機械学習」など）は寄せません。分野でしぼりたいときは分野チップを押してください。 主題の言い方で困るのは、収録の会議名が英語で書かれている場合です。こういう語は英語の語も調べて、件数欄に「「異常検知」は原文の anomaly detection という語で探しています」と出します。ただし エッジ には edge を寄せません – knowledge の中に含まれて CIKM や KR が出てしまうためで、edge computing だけに寄せています。会の催し物の言い方も同じです – ワークショップ は 74 件しか当たらず、会議名に Workshop と書く 52 件が抜けていました（セッション 学生 は 0 件）。今はどちらも調べて、件数欄に 「ワークショップ」は原文の workshop という語で探しています と出します。提案 募集 発表 を付けた形も同じです （ワークショップ提案 チュートリアル募集 学生発表 – 直し前は どれも 0 件でした）。 チップで絞ったときは件数欄に「分野「人工知能」を持たない行 N 件」も出ます。チップに書かれる件数はその分野の行の数、件数欄の件数は「他の条件を通った行のうち分野で落ちた数」なので、足しても全件にはなりません。 チップは Tab で届き、Space で入り・出ます（押しているチップには枠が出ます）。 チップに並ぶ語（システム（Systems, Architecture and Storage） のように日本語名へ英表記を併記した形）をそのままコピーして貼っても、その分野の行に出会えます – 括弧の中の英文字は日本語名の但し書きなので、検索語では落としてから引きます。人工知能 のように括弧の中が日本語のときは、今までどおり絞り込みとして効きます。チップの並びは日本語名の五十音順です。行に付く分野タグは収録の分野順のままです。

国内・種別・行の詳細

国内
情報処理学会・電子情報通信学会などの国内研究会と国内シンポジウムに絞ります。「国内研究会」のボタンでも同じ絞り込みができて、件数欄にはのぞいた件数も出ます。日本の開催かどうかとは別物で、日本で開催される国際会議（開催地が Tokyo, 日本 のように書かれる行）はここを付けると消えます。日本開催の会議を見たいときはチェックを外し、検索に「東京」「日本」などと打ってください。日本の行の開催地はローマ字で書かれていますが、漢字で打てます（東京 京都 名古屋 会津若松 など。会場名で行を書いている回は 一橋講堂 日本科学未来館 でも引けます。行には Aizuwakamatsu, 日本 のまま出ます）。宮古島 のように、寄せてあるものは公式の表記（Miyakojima, Japan）に対応しています。逆に、行の無い地名（宮島 など）は置いていません。
種別
表は投稿締切（概要・論文）だけを出します。採否通知・カメラレディ・登録締切・開催案内などは表に混ぜず、upcoming.html に載せます。種別の選択欄に並ぶのは、選べば結果が返る種別（概要・論文・常時受付）だけです。種別の下に小さく添える「原表記: …」は、収録元がその締切に付けた呼び方そのものです（画面の種別と並ぶ別の分類ではありません。既定画面の行はすべて原表記を持っています）。この語も検索で引けます。
行の詳細
行を押す（タップする）と、右から詳細の出る欄が開きます。行の文字をドラッグして選んだときは開きません（会議名・会場・公式ページの名前をコピーしたいときに、選んだ物が詳細の欄に隠れていたためです）。閉じるときは、開いた欄の右上にある ✕（閉じる）を押します。キーボードなら j / k で選択行を動かしてから d で開け、Esc で閉じられます。中身は、公式ページへのリンク、開催地と会期（JST と曜日）、分野、評価、締切の確認状況（いつ・何を公式で確認したかと、次回確認の予定）、日付だけが分かっている締切のただし書き、同じ研究会のこれからの回（研究会は毎月開くので、行をめくらなくても次の回が分かります）。一覧に出ない情報はこの欄に有りますが、投稿前に公式サイトで最新の募集要項を確認してください。

一致評価・意味検索・印

一致評価の出し方（投稿先を探す）

投稿先は、言葉の一致や意味の近さを使って並べます。意味検索が使えるときは、2つの検索の順位を合わせます。

候補は投稿先として適合を確認する対象で、強い一致も含みます。重なりうすいは言葉や意味の一致が弱い候補です。CSVの「一致の点」は並べ替えの目安で、採択される可能性の予測ではありません。

カードの「選定理由」で一致した要素を確かめ、会議名か「公式サイト」を開いて募集分野を確認してください。

カードの頭にある一致評価の下に、判断材料を4行並べます。収録データは収録した開催年の件数と論文サンプル数です。会議の年齢や査読品質を示す値ではありません。種別は論文募集・採択通知などの区別、締切の確認状況は日付・時刻・タイムゾーン・種別の確認状態、取得状態はデータを取得した状況を示します。保存済みのデータを使用している場合は、公式サイトで最新の締切を確認してください。
当たった要素の名前
投稿先を探す画面では、なぜその候補が出たかを当たった要素の名前で出します。短い名前は次の意味で使っています。会議名（会議名の内容語が論文のタイトルやキーワードに含まれる）、分野（会議の分野と論文のキーワードが一致。高性能計算・人工知能・セキュリティなど）、タグ（会議の主題が論文に書かれている）、採択論文（この会議で採択された論文に使われた語と一致）、日本語（日本語の会議名・論文語が一致）、過去掲載先（過去にこの掲載先への投稿が確認されている）。過去掲載先は主題の一致とは別の補助情報です。候補のカードでは「採択論文一致」のように語に「一致」を付けた書き方をします。もう 1 つ、「同じ分野（掲載先から推定）」という名前が並ぶことがあり、これは掲載先から推定した分野とこの会議が一致した意味です。逆に 「目立つ一致はない」と出ることがありますが、これは一致の数が少ないだけで、候補として出す最低の線は超えているという意味です（候補の組み立てが壊れた印ではありません）。複数の論文を入力したときは、論文ごとの行にも同じ名前を並べます。内訳に出る数字は上位何番目かという順位などで、一致スコア（点）を足して作った物ではありません（昔は手作業で決めた重みを足した数字を並べていて、画面の噓になっていたためやめました）。 締切の一覧に「一致評価 … ▾」ボタンがある場合は、Tab でチップに移動して Enter または Space を押すと内訳を開閉できます。 開いた内訳では、当たり方の説明を項目の下に書いています。スコア（点）はこの内訳を足した値ではありません。
意味検索が使えないとき
論文から投稿先を探しているとき、件数の欄に「意味検索は利用不可（語彙検索のみ・原因: …）」と出ることがあります。意味検索（文の意味の近さで探す検索）の仕組みが端末で動かせない代わりに、言葉の一致だけで順位を決めている、という意味です。候補そのものと一覧はそのまま使えます。原因は「意味検索のデータが読み込めませんでした」などの日本語で書きます（英字の符号は出しません）。モデルの読み込みは時間のかかる処理なので、時間を置いて再読み込みすると戻ることがあります。何度試しても戻らないときは、言葉の一致だけでの順位としてお使いください。
未確認
会期・開催地・ランクの値が空のセルは「未確認」と出します（「-」などの記号ではありません）。投稿先を探すモードのカードでも同じ語を使い、受付状況が確認できない行は「受付状況未確認」、受け付け中で次回の日付だけが出ていない行は「次回締切の日付が未確認」と出します。行の詳細の中にある公式確認の欄も、確認元が収録データに記録されていなかったときは「確認元 未確認」と、同じ語で出します（unknown や「不明」など、てびきに無い語は使いません）。会議側が未定にしていることとは別で、kamiyobi が公式で裏を取れていないという意味です。空のまま置きたくない情報は公式の発表を待つしかありません。その理由は行の詳細の本文にも同じ語で出します。
該当なし
「該当なし」は、もともと締切・会期・会場という物が無い行に出す印です。常時受付の期刊行がこれで、会期・開催地の列に「未確認」ではなくこの語が出ます（ジャーナルには会期も会場も無いので、公式の発表を待つ情報ではないためです）。「未確認」は kamiyobi が公式で裏を取れていないだけの印なので、同じ列に並べ分けています（混ざると、確認待ちの行かどうかを紙と画面で区別できません）。「該当なし」で検索すると、その行だけが出ます。印刷した用紙の但し書きにも同じ語の意味を書きます。
早め絞り込みのボタン
画面上部のボタン（「締切まで 7 日以内」「A*ランク」「高性能計算・システム」「国内研究会・国内シンポジウム」「オンライン参加可」）は、その条件だけを出し入れします。押すと入ってもう一度押すと外れ、押している間は点いたままです。点いていることは読み上げにも同じ状態として伝わります。入力済みの検索語や他の条件は消えません。条件を一度に外したいときは、0 件案内の「条件をまとめて外す」を使ってください。ボタンの語はそのまま検索欄にも打てます（A*ランク・A* ランクで同じ行）。等級の呼び方はこれだけでは止まりません – 『A 類』のような言い方も同じ行を出します。同じ系列で 『A クラス』の言い方も受け付けます。類 だけ・ランク だけでは等級を絞れないので、そのことは件数欄が出します。

開催地・オンライン参加可・ランク・会期

地名はひらがなでもカタカナでも
とうきょう おきなわ きょうと のようにひらがなで打っても、東京 沖縄 京都 と打ったときと同じ行が出ます。行の開催地は公式の表記のまま残っているので、日本語で打った人に届くようにするのは検索語の側だけです。
海外の開催都市
カタカナで引けます（リール ストラスブール チェジュ バンガロール など）。行には公式の英文字表記が残りますが、日本語の表記表が同じ都市のつづりに寄せます。カンクン・マルメ・テュービンゲン・マラガ・クラクフ・ロングビーチ・ヴェローナ・サクラメントなど、アクセント記号付きで収録されている都市もカタカナで引けます。ワシントン はワシントン州の行にも当たり、バリ はインドネシアの島とイタリアのバーリの両方に当たります（行の開催地に国・州が併記されるので、そこで判別してください）。
国内研究会・国内シンポジウム
「国内研究会」は検索の語としても引けます。行の名前に「研究会」と書かれた国内の行だけを指すので、チェックボックス（国内の行すべて）より狭くなります。
オンライン参加可
会場表記に「オンライン」「ハイブリッド」「Online」「Virtual」などの記述がある行だけを出します。記述が無い行を対面とは判定しません（公式サイトで確認してください）。会場名の一部として語が含まれる例（KSIR Virtual Conference Center）は除外しています。現在の件数は検索結果で確認してください。件数欄は「オンライン参加の記載がない N 件（うち開催地が未確認 M 件）」と分けて出すので、オンライン参加が無いのだと誤解しないでください。行の詳細には開催地の公式表記をそのまま載せています。（hybrid） のような対面併用の表記もオンライン参加可として数えます。このチェックボックスの語はそのまま検索の語にもなっていて、「オンライン参加可」「オンライン参加」「ハイブリッド」と打っても同じ行が引けます（広げた先は件数欄におしらせを出す）。
会期情報あり・投稿締切未収録
投稿締切が未収録の開催回は、締切一覧には出ません。直近の会期はupcoming.htmlで確認できます。検索結果が0件でも、同じ条件で会期情報が見つかればその場に案内します。締切一覧に行がある場合も、件数欄に「会期情報がある開催回」の件数を併記します。月のみ判明・日付未確認・未発表の区別は会期の表示で確認してください。期間の指定は会期に適用します。情報があれば、行の詳細の「今後の会期」に別の開催回も表示します。
ランク
「クラスA」は A と A* の両方に当たります。等級を正確に指定するにはランクの選択欄を使ってください。CCF・CORE・THCPL の評価一覧に基づきます。同じ会議でも一覧によって評価が違うので、絞り込みはいずれかの一覧その評価なら出します。評価一覧に載っているが評価が付いていないものは「CCF 評価なし」のように出します（データ内部の表記は N）。評価一覧そのものに載らない会議は「未確認」です。収録している穴場会議・ワークショップは基本的に載りません。 評価でしぼったときは件数欄に「評価「A*」を持たない行 N 件」も出します。選択欄には評価の収録数が写らないので、この数がないと「収録に A* が少ない」と誤解して絞り込みを外してしまうためです。評価なし を選んだときの件数欄は「評価なしの行以外 N 件」と出します – 絞り込みの値は N ですが、その語は一覧にも行の詳細にも出さない約束なので、件数欄でも選択欄と同じ語にします。

データ源・更新・会期・論文・カレンダー

データ源
画面下の「データ源」は、収録データがどの配布物に基づいているかの表示です。名前はリンクで、クリックするとその配布物のページ（一次資料）に飛べます。「このサイトで収録した分（上流にないもの）」は、上流の配布物に載っていない会議・締切をこちらで入力し、公式ページを確認して加えた分です（上流配布物のライセンスとは別の話なので、画面のこの項目にはライセンスを書きません。配布物の data.json では sources の local に、このサイト自身の配布物として MIT が入っています）。評価（CCF・CORE・THCPL）の出典でもあることは「ランク」の項に書いています。どこまでが公開済みかは「データ更新」を見てください。
データ更新
右上の「データ生成」がその時刻。JST と曜日で書きます（一覧と同じ単位）。掲載値は集約データと公式ページの自動確認に基づくが、投稿前に必ず公式サイトの募集要項を確認する。締切のデータが入っていない状態でページが開かれたときは、「データ生成」に未確認と出し、一覧の場所にもその旨を書きます（条件の話ではなく読み込みの問題なので、絞り込みを外しても行は増えません）。時間をおいて再読み込みするか、サイトの一覧を開き直してください。また、データは日次で更新する運用なので、生成から3 日以上経っている場合は「データは N 日前に生成されたものです」と出して、更新が止まっている可能性を伝えます（古い一覧を最新と誤って使い、投稿の機会を逃すのがいちばん悪い失敗のためです）。日数の数え方は一覧の「残り」と同じで、JST の暦日です（データ生成の時刻も JST で出しているので、隣に並ぶ日時とずれません。端末の時計が合っていないと、その分だけずれます）。
会期
会議の開催日程です。締切とは別の情報として、一覧・詳細・CSVで 2024-03-18(月) 〜 2024-03-21(木) のように表示します。曜日はその暦日に対応し、公式の原表記は詳細に残します。会期の日付も検索できます。開催日順に見るには「会期」列で並べ替えてください。「締切まで」は会期ではなく投稿締切からの日数です。
データの健全性（health.md）
この一覧の裏取りを、人の読める形に書いた報告を同じ場所に置いています （health.md）。 書いてあるのは – 収録している会議の件数、締切が時刻まで確定 / 日付のみ / 推定の 内訳、上流をその場であたったのか収録の snapshot から引いたのか、分野の内訳、解析で見つけた 注意、必ず収録しておきたい会議の名簿です。画面は推定を既定の一覧に出しませんが、報告には 件数が載ります。機械が読む形は同じ場所の health.json です。
AI に聞く
llms.txt に、機械向けのファイル一覧と検索の読み方があります。リポジトリを手元に置いている場合は、node src/mcp.ts で起動する読み取り専用のMCPサーバーをAIのツールとして登録できます。画面と共通の検索処理で、締切検索・直近の締切と会期・会議ごとの開催回・用語の案内・収録件数・投稿先検索・投稿先推薦を取得します。MCPサーバーは外部通信やデータの書き込みを行いません。
論文の入力とサンプル
「投稿先を探す」には、投稿予定の論文を PDF・TXT で選ぶか、下の欄に直接打ちます。欄の下の「入力の例」のボタンは、押すと欄の中身をその例に入れ替えます。すでに打ち込んだ物があるときは、押した直後に「直前の入力に戻す」が出るので元に戻せます。PDF・TXT を選んだときの差し替えも同じボタンで戻せます（「複数可」とあっても、新しく選んだ物で入れ替わります）。押すと検索も一緒に走るので、入力の形を確かめたらそのまま候補を見られます。
カレンダーに追加（.ics）

「カレンダーに追加（.ics）」は deadlines.ics を開きます。収録している今後の締切が全て対象で、画面の絞り込みは引き継がれません。採否通知・査読結果公開・反論期間の開始なども含みます。会期自体の予定は作らず、各予定の本文に会期を記載します。

各予定は終日で表示します。時刻が分かる予定はJST の暦日、日付のみの締切は公式の日付を使います。継続時間や時間帯は作りません。公式の時刻がない締切は「時刻未確認」、推定日程は「推定」と表示します。「要確認」「延長後」などの状態も本文に記載します。

分野名は画面の分野チップと同じ日本語で、本文と分類欄（CATEGORIES）に入ります。カレンダーアプリが分類欄を表示しなくても、本文を「セキュリティ」などの語で検索できます。収録件数と期間は、一覧の上のカレンダーの説明欄で確認できます。画面の一覧より先の締切も収録しています。

更新を受け取るには、カレンダーアプリの購読先（URL）に指定してください。「購読 URL をコピー」でURLを取得できます。自動コピーが使えない場合は、画面に表示されたURLをコピーします。データは毎日、日本時間の朝に更新する運用です。ダウンロードしたファイルは保存時点の写しで、自動更新されません。

絞り込んだ締切だけを保存するには「この一覧の N 件をカレンダー（.ics）でダウンロード」を押します。「投稿先を探す」では「この候補 N 件をカレンダー（.ics）でダウンロード」となり、カードと同じ候補の締切を書き出します。候補は「この候補 N 件を CSV でダウンロード」でも保存できます。これらも保存時点の写しなので、一覧が変わったら保存し直してください。
